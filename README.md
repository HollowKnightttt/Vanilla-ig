# 📝 Option 1: Poggit / Plugin List Description (Recommended)
Vanilla IG
The ultimate vanilla block expansion plugin for Nukkit servers.
Vanilla IG brings a rich set of vanilla-style block variations and custom additions to your Nukkit Bedrock server. Designed to seamlessly integrate with native Minecraft gameplay, this plugin allows server owners to add missing block types, custom vanilla-friendly variations, and enhanced building blocks without breaking the classic feel of the game.
# ✨ Key Features
 * 🧱 Seamless Integration: Adds custom vanilla blocks that feel native to Minecraft Bedrock Edition.
 * ⚡ High Performance: Lightweight and optimized specifically for Nukkit software to ensure smooth server performance.
 * 🛠️ Easy Configuration: Simple setup and customizable block properties via configuration files.
# ⚙️ Installation
 * Download the latest .mcaddon release of Vanilla IG.
 * Place the file into your Nukkit server's addons/ directory.
 * Restart your server to generate default configuration files.
